
## Individual Project - Sofia Karamichali 

GUID: 2570646K

Project Topic: Analysis of gender stereotypes in personality assessments of recorded speech

Supervisor: Dr Evangelia Fringi

### Overview
The code is designed to assess the dataset included in `data/` to determine whether gender stereotypes impact personality perceptions based on non-verbal cues. The experiments conducted include statistical analysis, machine learning methodologies and within gender assessment of audio features and personality scores.


Overview of the folder structure:
* `timelog.md` The time log for the project.
* `plan.md` A skeleton week-by-week plan for the project. 
* `data/` data used
* `src/` source code
* `status_report/` the status report submitted in December
* `meetings/` Records of the meetings you have during the project.
* `dissertation/` project dissertation
* `presentation/` presentation
