# User manual 
To run the software, simply run the various ipynb files.
All dependencies are included in the requirements.txt file and can be installed by running: pip install -r requirements.txt.

The code is organised as follows:
* statisticalAnalysis.ipynb consists of the findings for the statistical analysis section of the project. This file uses functions from dataManipulation.ipynb
* models.ipynb consists of the code using scikit-learn which trains and tests the machine learning models used in the project.
* audioCorrelations.ipynb consists of the code for the within gender assessment section of the project.
